# README assets

Assets used by the project README.

- **`icon.png`** — the app icon shown in the README header. Regenerate from the source
  icon with: `sips -s format png Resources/AppIcon.icns --out docs/icon.png && sips -Z 256 docs/icon.png`.
- **`comparison.png`** — the menu bar treatment comparison shown near the top of the README.
- **`screenshot.png`** — a full capture of the settings popover, kept for documentation and releases.
- **`PRESETS.md`** — the complete built-in preset catalog and preset-sharing guide.
- **`preset-previews/`** — compressed WebP previews used by the preset catalog.
